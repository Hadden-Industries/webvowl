### Acceptance criteria

- AC-001: The normal interface works without WebMCP. A supported top-level page
  registers fourteen bounded non-editing tools and disposes their registrations;
  experimental ontology editing has no agent action.
- AC-002: Human controls, WebMCP and tests use one application controller. The
  rendered-graph runtime is the sole application rendering interface, its D3
  adapter is the sole production implementation, and replaced graph/options,
  callback, loader and exporter routes are removed without compatibility shims.
- AC-003: New and materially reshaped production modules use native ESM with
  explicit relative extensions and accurate controlled vocabulary. The production
  CommonJS allowlist is empty; diagrams and executable architecture checks match
  ownership and prohibit application-to-D3 and renderer-to-UI dependencies.
- AC-004: Application-owned ontology/VOWL inspection is available independently
  of rendering. Summary, search, relationships, annotations and localized details
  use immutable snapshots and distinct semantic, document and arrangement
  references; visual proximity is not treated as an ontology fact.
- AC-005: Generations and document revisions have distinct lifetimes. Stale load,
  layout, view, paint and export work cannot overwrite the current visualization;
  cancellation preserves valid state, and initial render completion requires
  painted current geometry.
- AC-006: Human and agent viewing actions share loading, language, filters and
  degree, search/details/selection/focus, pause/resume, zoom and center, pan,
  distances, modes, reset, arrangement, share links and supported exports. Controls
  reflect actual applied state. Existing human experimental editing remains
  usable and accepted changes reach inspection, recovery and exports.
- AC-007: Strict export observes bounded layout stability; best-effort export
  requires an explicit request. One detached styled SVG implementation preserves
  the live graph, produces matching bytes, dimensions and SHA-256, exposes the
  actual local artifact and retires obsolete URLs. Turtle generation is preserved;
  this work changes its wiring only.
- AC-008: Closed tool inputs/results preserve source-loading restrictions,
  cancellation and bounded output. Tool results exclude ontology/VOWL/SVG source,
  download URLs, credentials, stack traces and unbounded parser diagnostics while
  useful human diagnostics remain available.
- AC-009: The motivating AQFO job produces a source-grounded, independently
  inspected SVG framed around the requested IRI. Twenty native evaluation jobs,
  relevant automated checks, independent correctness/security coverage and owner
  acceptance establish the recorded outcome; client attachment and host/browser
  limitations remain explicit rather than being converted into passes.
- AC-010: Preserve the accepted licence, pinned owlapi ownership, configuration
  approvals and unrelated work. Retain original failures and review evidence.
  Implemented viewing/startup/editor regressions are corrected. Merge acceptance
  does not authorize deployment or universal browser/client certification.

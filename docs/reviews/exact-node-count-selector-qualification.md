8 October 2026. Source delivery only; deployment and production acceptance were not authorized. The accepted plan amendment settles snapshot persistence, producer ranking identity and available-device qualification.

## Implemented behavior

Fresh sources and presets use Auto, exactly `min(50, eligible nodes)`. All follows eligibility; exact intent preserves its requested count across filter shortfalls. Classes and datatype occurrences count separately, including repeated glyphs for one semantic entity. Non-count filters and restored hiding define eligibility before ordering. Selection is a nested prefix of a complete, cached `connected-sqrt-v1` permutation. Surviving incidence uses unique other neighbors, separate incident-edge counts, structural producer keys, connected frontier ordering and square-root component fairness. Count-only incidence updates visit changed prefix nodes and their edges/labels; materializing scene arrays and rendering still cost work proportional to the document.

Live hidden provenance separates count suffixes from restored/upstream hiding. Snapshots save complete appearance using the existing format and reopen with All of restored eligible nodes. URLs and WebMCP preserve Auto/All/exact intent. Saved URLs with exactly `doc=0` reopen with All under the owner's explicit migration exception. Other old `doc`, `minDegree` and proposed `nodes` inputs fail with correction advice, including mixed requests. New links emit only `nodesShown`; programmatic/WebMCP inputs keep their strict rejection. No active degree implementation, event, DOM hook or renderer default remains. Count-hidden search results offer an explicit reveal; upstream-hidden results remain unavailable. Operators disclose omitted operands.

## Recovery and source acceptance

Reject invalid or obsolete intent before mutation. Failed current view application restores the previous hiding and count intent; newer requests abort older pending work and guard completion by document/view revision. Worker identity remains subject to VOWL limits and cancellation. No viewer canonicalizer, degree-to-count conversion, fallback identity or second renderer authority is introduced.

An old reader does not preserve `nodesShown` URL intent. A source downgrade therefore requires corrected links or a forward fix, not a claim of transparent migration. Existing canonical snapshot bytes retain their profile and can be read by the prior reader. Source delivery does not certify timing hypotheses, unavailable AT/device evidence or production deployment.

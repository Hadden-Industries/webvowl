# Independent field-contract supplement

This additive corpus closes a finite, declared A1–A5/B1/B3 field-mutation denominator.
It preserves every prior producer, index, manifest, expected file and specification hash.
No production source, schema, helper, test or output was used to derive the inventory or expectations.
The unchanged amended A6 producer remains a trusted-fixture mapper, not a complete validator.

The [contract inventory](contract-inventory.json) transcribes 124 record/variant descriptors and 414 field positions.
Its 3,369 obligations comprise 698 positive bindings and 2,671 negative mutations.
The [binding inventory](coverage-inventory.json) binds every cell to exact independent evidence.
Discriminated-family selector guards are shared across the family's branches; nested descriptors are exercised at distinct semantic positions rather than multiplied across every parent combination.
Forbidden-field classes enumerate sibling-only and explicitly prohibited fields plus one representative arbitrary unknown name.
This is a finite class denominator, not every possible JSON member spelling or malformed JSON value.

The new positive manifests are:

- [Supported embedded assertions](positive-manifest.json): 29 additions complete all 32 legal embedded Assertion alternatives across the combined corpus.
- [Additional field witnesses](additional-positive-manifest.json): nine cases complete the seven embedded object-characteristic values and provide valid alternative reference targets for isolated sort/cardinality failures.
- [State-only ID change](state-identity-manifest.json): two artifacts have identical named structural source; changing one x coordinate from 0 to 1 swaps the two role and occurrence ranks.
  [Semantic associations](state-identity/associations.json) record the exact relationship, without relying on anonymous graph automorphisms.

Each positive pins source, typed permutation, mapped dataset, canonical N-Quads, fixed-input ID correspondence and exact canonical bytes.
Complete bytes and canonical datasets reproduce under typed handle renaming, set reversal and object-key reversal, with property-chain order preserved.

The [early negative manifest](early-negative-manifest.json) contains 23 frozen cases.
The [full negative manifest](negative-manifest.json) reuses 21 of those inputs and binds all 2,671 field-negative cells.
Run the two early precedence cases separately rather than executing the reused IDs twice.
All mutations begin with an independently valid source or canonical document.
Required/forbidden/type/cardinality/typed-reference failures are distinct obligations; a positive token occurrence alone does not satisfy them.

The separate [semantic inventory](semantic-inventory.json) has 437 obligations: 433 new [decoder/profile/scalar/precedence negatives](semantic-negative-manifest.json), two linked early precedence cases and two exact known-profile positives.
Every canonical closed record/variant has decoder required, forbidden and type witnesses; discriminator families, the narrower Literal union, exact profile strings, profile/state coupling, lexical-domain positions and listed precedence cases have explicit entries.
Five further [stage overlaps](semantic-overlap-manifest.json) were independently authored after review feedback.

Positive camera zoom has a pending stage/code interpretation conflict. The frozen semantic manifest expects `ARTIFACT_INCOMPLETE` for zero and negative zoom from A7's stage-7 camera invariants. An independent protocol reviewer reads B3's greater-than-zero constraint as a stage-4 scalar domain with `NUMBER_INVALID`. The reference/ID/projection-plus-zero-zoom overlaps depend on the same question. Both readings and the original expectations remain visible pending an explicit normative decision; implementation behavior alone does not decide them. The three prior lexical/direction questions remain in the [historical review supplement](../review-resolution-v1/review-resolution.json).

The [mapping pair inventory](mapping-injectivity-inventory.json) is intentionally separate.
Excluding 66 primary handle positions and classifying five serialized-envelope mirrors separately leaves 343 retained source-field positions.
A conservative exact-one-field audit establishes changed full datasets and bytes for 35 positions, with all 36 selected source witnesses independently reproduced and permuted.
The other 308 positions are explicitly unclosed, as is a dedicated profile-framing pair.
Composite owning-field substitutions do not establish nested-field coverage.
These gaps prevent an exhaustive D18 mapping-injectivity or profile-freeze claim.
